# Plan: Issue 40 - Weapon and loot icons for UI do not exist

## Exhaustive Outline
Currently, there are no graphical icons for weapons or loot items in the game. This prevents the inventory and loadout screens from displaying items properly to the player. The goal of this task is to create one distinct image for every weapon and loot category in the game while ensuring all new artwork strictly follows the established color palette and visual style.

## Step by Step Execution Instructions

1.  **Gather the Item List:**
    Retrieve the final approved list of all weapons and loot categories that need artwork. 
2.  **Review Art Guidelines:**
    Check the master icon color palette to ensure all new drawings will match the existing game style.
3.  **Draw Weapon Icons:**
    Create one icon for each weapon on the list.
4.  **Draw Loot Icons:**
    Create one icon for each loot item or category on the list. Ensure these look visually distinct from the weapons.
5.  **Add to the Game:**
    Place the finished images into the correct folder and link them so they appear on the inventory and loadout screens.

## Verification Steps
1.  Launch the game and open the inventory screen.
2.  Equip different weapons and verify that the correct picture appears for each one.
3.  Collect various loot items and verify that the correct picture appears for each category in your inventory.
4.  Visually compare the new icons against existing game menus to confirm the colors match the required style.

## Completion Checks
*   [ ] One icon created for every weapon in the final roster
*   [ ] One icon created for every loot piece or category
*   [ ] All icons strictly follow the required color palette
