# Plan: Issue 41 - Bestiary thematic divergence: half the enemy roster reads as fantasy monsters, not the pitch's household

## Exhaustive Outline
The problem is that half of the enemies currently planned for the game do not match the original creative vision. The initial idea focused on a human threat, featuring household guards like watchmen and sergeants. However, the current enemy list includes magical creatures and constructs, such as flying wisps and hovering spellcasters. The goal of this task is to decide how to resolve this mismatch. The team must choose to either redesign the magical enemies to fit the human theme, update the original vision to include magical elements, or create a specific rule for where magical enemies belong. Finally, this decision must be documented.

## Step by Step Execution Instructions

1.  **Review the Options:**
    Read the three proposed solutions: redesigning the five magical enemies to be human guards, updating the original vision to include magic, or splitting the game areas to allow monsters only in specific zones.
2.  **Make a Decision:**
    Consult with the creative team to select one of the three options to align the game's direction.
3.  **Document the Choice:**
    Open the project decisions file and write down the final choice clearly so the entire team is aware.
4.  **Update Related Files:**
    Depending on the choice, update either the enemy list file to feature human enemies or the project vision documents to include the new supernatural elements.

## Verification Steps
1.  Read the decisions file to confirm the choice is recorded clearly.
2.  Review the enemy list or the vision documents to ensure they match the recorded decision.
3.  Ask a team member to read the updated documents to confirm the creative direction is clear and consistent.
