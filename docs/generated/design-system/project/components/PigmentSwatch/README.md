A colour chip card: a solid colour field over a name and hex value, with a
one-line usage note. Used to present the pigment palette itself.

## Guidelines

- Chip height is fixed (104px in the source); name is `display.term`,
  hex value and usage note are `mono.value` / `body.caption`.
- Cards sit in a hairline grid (1px gaps in `line-soft`), never with rounded
  corners or a shadow.
- The usage note should always say what the colour means, not just where it
  appears -- see the palette discipline in the system README.
