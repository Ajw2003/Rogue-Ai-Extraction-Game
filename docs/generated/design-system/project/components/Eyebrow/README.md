A small mono micro-label with a trailing hairline rule, used above every
section heading and card group in the identity.

## Guidelines

- Always mono (`mono.eyebrow`), uppercase, letter-spaced.
- Colour is `vellum-faint`; the trailing rule is `line`.
- Use to introduce a section or group -- never as a standalone caption on its
  own, and never in `body`/`display` type.
